# Sistema de Atendimento — Atualizações

Repositório público destinado exclusivamente à distribuição de atualizações do **Sistema de Atendimento**.

## Finalidade

Este repositório armazena apenas os artefatos necessários para atualização do aplicativo, como:

- instalador `.exe`;
- arquivo `latest.yml`;
- arquivo `.exe.blockmap`;
- releases versionadas do sistema.

## Importante

Este repositório **não contém o código-fonte** do Sistema de Atendimento.

O código-fonte, credenciais, chaves privadas, tokens, segredos de instalação e arquivos internos permanecem fora deste repositório.
